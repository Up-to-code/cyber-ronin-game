# World migration contract

User objective: replace repeated horizontal patrols and cosmetic monster variants with purposeful traversal, distinct worlds, interactive abilities, bosses and readable expressive combat.

Ownership: root integrates main scene/world presentation and reviews evidence; world_migration owns campaign/routes/camera; creature_migration owns roster/enemy/boss mechanics and art; player_abilities owns hero/VFX/earned abilities/devices. Shared main scene changes belong to root.

Acceptance:
-100 routes include upward, downward, switchback and return traversal; platforms serve a landing, encounter, optional reward or puzzle purpose.
- Surface, underground, sky and historic citadel use different world art and platform materials.
- Each route introduces a monster identity; creature art and attack contracts must distinguish actual new artwork from reused motion.
- Every tenth route ends in a boss. Broodmother releases capped children and the exit remains locked until they die.
- Earned limited-use powers solve real devices and retry cannot strand the player. Portals visit a distinct pocket realm and return safely.
- Jump/attack/reversal feedback preserves responsive control, visible contact timing and bounded effect counts.
- Parent reruns representative actual inputs, transition/reset tests, native captures and packaged build. Route geometry checks alone are not a full playthrough.

Research principles (inspiration, no copying assets/maps):
- Ubisoft describes powers that link combat, platforming and puzzle solving: https://news.ubisoft.com/en-au/article/e1SD5gR3TWqk5GPAjWHSz/prince-of-persia-the-lost-crown-will-put-your-combat-platforming-and-puzzlesolving-skills-to-the-test
- Dead Cells describes nonlinear progression and alternate paths: https://deadcells.com/
- Team Cherry discusses Hollow Knight's world and visual style: https://www.teamcherry.com.au/blog/introducing-hollow-knight
- Celeste emphasizes handcrafted ascent challenges: https://www.celestegame.com/

Design application: teach one mechanic safely, test it in a changed spatial situation, combine it with one earlier idea, then give a rest/landmark. Vary route direction and player decision, not only coordinates. Boss phase changes must alter player response, not just health.
