# Living marsh art

Generated with built-in image_gen: distant marsh/shrine background and a four-frame fire loop. Raw RGBA/source images and exact prompts are preserved in source/. Engine-scale nearest-neighbor exports are in game/art/living-marsh. tools/prepare_living_marsh.py reproduces the deterministic crop/resize pipeline.

- Background prompt: source/livingBg.prompt.txt
- Fire prompt: source/livingFire.prompt.txt

The game retains separate distant and near scenery at different parallax speeds, with subtle scenery drift. Ambient particles now mix falling ash with rising embers. Fires use one generated four-frame action, three silhouette proportions and offset speeds/phases; they are not three independent generated animations.

A reversal during a sword combo opens a0.30-second opportunity for the next J tap to select a return-sweep clip. Facing remains immediate. The current strike is never restarted and no extra hit is generated by the direction change alone. Uses existing authored character cels with dedicated timing, not new body drawings.

Validation: moving_sword_facing covers queued return sweep, turning, held-direction four-hit chain and aerial reversal; combat_expansion passes. Native level42 screenshot and living-marsh-combat.mp4 were inspected/captured. Rebuild the standalone app with scripts/build_local_macos.py.

## Seam repair and mist layer

Added generated mist source and prompt (`source/mist.png`, `source/mist.prompt.txt`) and engine export `game/art/living-marsh/mist.png`. The background now has four layers. Layout uses each texture's actual dimensions, a shared vertical offset per row, integer tile pitches, and overscan above/below the viewport. This fixes the 768x256 skyline being laid out as640x360, independent tile bobbing, chopped canopy tops and exposed lower texture boundaries. Layer Z order remains stable as extra tiles are allocated for wide windows.

`tests/background_coverage.gd` passes12 viewport/camera combinations, including negative scroll, high/low camera positions, portrait and ultrawide dimensions. Native frame inspected at `docs/qa/background-seams-fixed.png`.
