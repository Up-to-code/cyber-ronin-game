# Lancer and hammer sentinel

Generated2row8column enemy pose sheet for Ashen Veil; originalraw retained. tools/pack_ashen_enemies.py alpha-cleans, uniformly scales eachcharacterrow, mirrors leftfacing art into the engine's rightfacing convention, registers the baseline and packs128×128cells with a48colorpalette. Newprofiles provide sparse idle/gait/windup/contact/hurt/death poses. This is not a completed high-frame-count animation library.
