# Ashen Veil assets

Generated through image-generation skill for this project. Raw welcome, branded icon and five-button atlas are retained. Runtime derivatives use nearest-neighbor resizing and binary transparency for buttons. Welcome640×360 is quantized48colors without dithering. Branded icon1024/256/64 exports preserve the square composition. Combat cells64×64: sword square,kick circle,power circle,ranged circle,energy circle. Artwork does not define hit testing; control code owns fixed responsive targets.
